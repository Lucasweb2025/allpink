# 🎀 All Pink Beauty - E-commerce Experience

Um catálogo interativo e luxuoso para produtos de beleza, desenhado para oferecer uma experiência premium e fluida no mobile. O projeto é dividido em um aplicativo de vitrine para o cliente e um painel de controle restrito para a gestão do catálogo em tempo real.

## 🚀 Funcionalidades

**Aplicativo do Cliente**
- Interface *mobile-first* com navegação por botões ou gestos (swipe).
- Design elegante com suporte nativo a Modo Claro / Modo Escuro.
- Carrinho de compras dinâmico com cálculo de totais.
- Checkout inteligente com direcionamento automático do pedido formatado para o WhatsApp.
- Catálogo sincronizado com a nuvem (sem necessidade de recarregar a página).

**Painel Administrativo (Admin)**
- Tela de login com acesso restrito por senha.
- Formulário de cadastro de produtos (Nome, Preço, Cor de Fundo da embalagem).
- Sistema de upload de fotos com pré-visualização e conversão automática da imagem para o banco de dados.
- Listagem e exclusão de produtos do catálogo ativo com um clique.

## 🛠️ Tecnologias Utilizadas

O ecossistema foi construído utilizando tecnologias modernas e sem dependência de frameworks pesados, focando em performance:

- **Front-end:** HTML5, CSS3 (Animações avançadas, Variáveis CSS, Glassmorphism) e Vanilla JavaScript (ES6+).
- **Back-end / Database:** Firebase Realtime Database para sincronização de dados instantânea entre o painel e o aplicativo do cliente.
- **Hospedagem:** GitHub Pages.

## ⚙️ Como testar o projeto

1. Acesse o link do projeto hospedado no GitHub Pages.
2. A tela inicial apresentará o aplicativo de vendas pronto para simular pedidos.
3. Para acessar o painel de gerenciamento, adicione `/painel.html` ao final da URL oficial.
